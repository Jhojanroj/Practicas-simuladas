# Sistema de Gestión de Reservas

## Descripción
Este proyecto consiste en el desarrollo de un sistema de gestión de reservas utilizando Python y Programación Orientada a Objetos (POO). Permite administrar clientes, servicios y reservas de manera organizada.

## Funcionalidades
- Registro de clientes
- Gestión de servicios (Reserva de sala, alquiler de equipos, asesoría)
- Creación de reservas
- Cálculo de costos
- Manejo de excepciones personalizadas
- Registro de errores en archivo logs.txt

## Tecnologías utilizadas
- Python
- Programación Orientada a Objetos

## Estructura del sistema
- Clase Cliente
- Clase abstracta Servicio
- Clases derivadas (ReservaSala, AlquilerEquipo, Asesoria)
- Clase Reserva
- Manejo de errores y logs

## Ejecución
Para ejecutar el sistema:
